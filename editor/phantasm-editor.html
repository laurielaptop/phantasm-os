Uncertain disk completion: recovery

Power cycling discards unsaved device patch edits and unsaved user-wave uploads from external tools. The editor cannot detect those external changes. Keep this page open and export local work when possible; local work is lost on reload or close. Patch/bank .syx exports contain no wave audio, and patch Save 23 does not persist user waves.

Stop transfers, disconnect MIDI ports, power-cycle the instrument, wait until boot is ready, clear MIDI interface queues, then explicitly confirm recovery in Setup before reconnecting and discovering the device. Release firmware requires a real power cycle; the Record-button soft reset is development-only. Follow these steps even when firmware/version discovery is unavailable. Do not save, use Panic or send any other MIDI while disk completion is uncertain.

Confirm only after completing those physical steps while disconnected. Elapsed time, reconnecting and clicking confirmation do not establish that an operation stopped. This button sends no reset command and cannot verify a power cycle.

Use Connect to request MIDI and SysEx permission, then choose the Mirage’s input and output and connect the selected ports. Web MIDI/SysEx support and permission are required; see the README for validated browsers and launch modes. If permission is denied, allow MIDI/SysEx access in the browser’s site settings and try Connect again.

After changing the loaded patch on the Mirage front panel, use Refresh device lists to inspect its palette. The opened local patch retains its own SELECT ranges. If discovery fails, check both cables and port choices, then refresh. Unsupported firmware stays read-only; use a matching Phantasm build.

The editor checks Phantasm protocol 4.0 / schema 1.16 and the generated schema/layout before allowing writes. A file or port name cannot establish compatibility.

Instrument tuning

Master tune and Transpose are instrument globals, not patch data. Values start Unknown. Read instrument tuning, enter whole-number drafts, then Apply: each changed setting is sent, acknowledged and read back, and only a matching readback confirms it. A timeout or refusal is never retried; read to reconcile before deliberately reapplying. Opening or auditioning a patch does not replace tuning.

Confirmation is RAM-only and applies at the next note-on; Apply sends no disk Save. A later reviewed patch Save can persist changed instrument globals, including tune and transpose, channel and omni. Patch storage can succeed while globals persistence fails; RAM readback cannot prove disk persistence, and the editor cannot detect panel or external changes. Transpose does not change key tracking, key speed or fixed-rate noise; master tune also affects fixed-rate noise.

Controller routing

Choose a separate controller keyboard input. Only notes, pitch bend, channel pressure, mod wheel, sustain and CC120/121/123 are forwarded on the Mirage’s basic channel; parameter controls and program changes are filtered. CC120/123 stop notes; CC121 resets bend, wheel, pressure and sustain while retaining held keys. Panic also resets controllers. Playing pauses during discovery and transfers. Never route the Mirage’s own output back as a controller.
