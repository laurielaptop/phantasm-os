    Setup

    Help / About

    Phantasm Editor . Editor version is separate from the instrument firmware shown below. Targets Phantasm v1.2.0, protocol 4.0/schema 1.17. Implementation is complete; release qualification is incomplete and no release is published.

    Getting started

    1. Use an up-to-date Chrome on a laptop. Open from HTTPS, localhost or the standalone HTML. Android tablet Chrome is an intended target awaiting device qualification; current Chromium alternatives are unqualified. No tested minimum browser version is claimed. Native file interaction, Android and physical MIDI acceptance are separate checks.
    2. Press Connect to request MIDI and SysEx permission. Choose Mirage in/out and optionally Controller in, then Connect again. Editing and transfers require compatible discovery. Port choices are remembered; the editor never connects automatically.
    3. In Edit, Load selects a disk patch and reads it, Get reads the instrument’s RAM edit buffer, and Import opens a local .syx patch. New and Import stay local until Send. In Library, Import opens a local bank; tap a member to edit it.
    4. Once Load, Get or Send has confirmed the edit buffer, live parameter controls change instrument RAM immediately without a dialog. Setup tuning drafts send nothing until Apply, which changes RAM without another confirmation. Neither saves to disk.
    5. Send replaces the instrument’s RAM patch and reads it back; it does not save to disk. Its review normally appears once per connection. When chord capture may differ, Send asks again and offers Get chord first; Save reviews also warn about capture. Get chord first reads/adopts the chord; review again to write.
    6. Load, Save, Save as… and advanced bank operations review disk access. Loads/reads can discard unsaved device edits. Save and Save as… overwrite a disk patch, reload and verify it; they may also persist changed instrument globals, including tuning, channel and omni. Patch storage can succeed while globals remain unconfirmed. Send again before live editing.
    7. Export downloads your local patch or bank. Local patch/bank work is lost on reload or close: export before closing. Files include palettes but omit waveform audio and instrument globals; they are not a complete instrument backup.

    Using older patches

    Keep original .syx files unchanged and establish source firmware/schema and disk/wave-pool provenance. Raw .syx has no version marker. Legacy sizes and slot-addressed files are rejected without conversion. Accepted size does not prove compatible meanings: pre-1.16 ENV3 destinations 1–3 changed meaning, and v1.1.0/schema 1.16 reserved patch bytes 74–80 become v1.2/schema 1.17 chord offsets (values above 127 are rejected). Same-size older files cannot be identified automatically. Import preserves accepted bytes; no automatic migration or sound equivalence is provided. Patch/bank files depend on the destination wave pool.

    Reporting a problem

    Before reloading, use Setup → Copy diagnostics, or More beside a status error. If clipboard access fails, copy the displayed text in Setup. Include editor version, browser/OS, served or standalone launch, steps and failure details. Review before sharing: filenames can appear in warnings, and browser error text or MIDI payloads can contain other private details. Remove private details from the shared copy, retaining relevant bytes, versions and failure causes where possible. The log is not automatically redacted or sent anywhere; it stays in memory and clears on reload.

    Details

    Device compatibility has not been verified.

    Boot display: 1.2 is a release build, 12 a development build; it does not show the patch number. Only discovery decides compatibility, not the OS version, a file or a port name. Unsupported firmware stays read-only.

    Tuning

    More

    Master tune and Transpose are instrument settings, not patch data. Apply sends each change and needs an acknowledgement and matching readback. A timeout or refusal is never retried: Read before applying again. Opening a patch does not change tuning.

    Confirmed values are in RAM only and apply at the next note. Apply never saves to disk; a later reviewed patch Save stores them with the channel and omni, and can store the patch while these fail. Panel or other-tool changes are not detected. Transpose leaves key tracking, key speed and fixed-rate noise alone; Master tune also moves fixed-rate noise.

    Disk recovery

    Recovery steps

    Power-cycling loses unsaved device patch edits and unsaved user waves from other tools; the editor cannot see those. Export local work first and keep this page open: reloading or closing loses it. Patch and bank .syx files hold no wave audio, and Save 23 does not keep user waves.

    1. Stop transfers and disconnect the MIDI ports.
    2. Power-cycle the instrument. Release firmware needs a real power cycle; the Record-button reset is development-only.
    3. Wait until boot is ready.
    4. Clear the MIDI interface queues.
    5. Confirm below, then reconnect and discover the device.

    Follow these steps even without version information. Until then, do not save, use Panic or send any MIDI. Confirm only after the steps, while disconnected: time, reconnecting or this button cannot prove disk activity stopped, and it sends nothing.

    Troubleshooting

    Copies the recent MIDI log for a problem report: bytes sent and received, decoding decisions and transfer outcomes, with editor/device identities and port names. Review before sharing: filenames can appear in warnings, and browser error text or MIDI payloads can contain other private details. Remove private details from the copy you share, keeping relevant bytes, versions and failure causes where possible. The log is not automatically redacted or sent anywhere. It is kept in memory only and cleared on reload.

    Permission

    Connect asks for MIDI and SysEx access. If it was denied, allow MIDI in the browser’s site settings, then press Connect again.

    Ports

    Choose Mirage in and Mirage out, then Connect. If discovery fails, check both cables and port choices, then Refresh device lists. After loading another patch on the Mirage panel, Refresh to read its palette; an open local patch keeps its own ranges.

    Launch mode

    Use an up-to-date Chrome on a laptop. Android tablet Chrome is an intended target awaiting device qualification; current Chromium alternatives are unqualified. Open from HTTPS, localhost or the standalone HTML. Native file interaction and physical MIDI need separate checks. See Help/About and the README for recorded evidence.
